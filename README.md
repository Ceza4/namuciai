# Namučiai

Notes, shopping cards, dinner and date matching, and daily chores for two, as a Home Screen web app.

- `src/main.js`, `styles.css`, `index.html`, `sw.js.tpl`: the app
- `supabase/functions/`: `notify` (web push with quiet windows) and `signup`
- `./build.sh` builds the site into `dist/`; GitHub Actions publishes it to Pages on every push to `main`.
